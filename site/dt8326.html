Share excludes (directory and extensions)

Post by Lindset » 2004-02-22 11:01

Would be good if it was possible to choose directories to exclude from the sharelist. I have a directory, which contains a directory that eMule is using for temporary downloads. When I want to share the parent directory, there's no way of excluding the eMule directory, which in return gets me banned from some servers

-- Downloads <- that's the one I'm sharing
---- eMule
--------incoming
--------temp <- that's the one I want to exclude

I'm sure there's someone else than me who would appreciate this...

It would also be great if it was possible to exclude all files with certain extensions. Like for example adding: "*.tmp;*.dat;*.part" to a textbox

Would make everything so much easier.. At least for me.. Don't feel like reorganizing my harddrive just for direct connect

Cheers

Sharing any of your Download folders is plain stupid, and will get you banned on a lot of hubs. Coming from eMule, it is perhaps not a big priority for you, but a lot of hubs require your share to be sorted, not just a thousand files thrown together in a download folder.

If you don't feel like making it easier for people to find files from you, perhaps you should choose another p2p network that doesn't have the same requirements?

Some DC++ Mods allow you to exclude certain files from your filelist, check out oDC and FulDC.
