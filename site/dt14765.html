yo-yo~delta wrote:Is it whenever you connect to them by trying to download a file fomr them?
You probably have "Automatically match queue for auto search hits" checked. You can check the help file (press F1) for more information about this feature.

Re: TTH alternative searching, and sources

Post by GargoyleMT » 2005-01-24 17:04

yo-yo~delta wrote: in a slow manner so there is no search spam problem?

DC++ should be good about not causing search spam, except if you manually search too close to one of its autosearches.

If you see "detected search spam from ..." often, it could be the hub's connection being saturated, or your own. Spacing out autosearches for everyone else is a band-aid over your own issue.
