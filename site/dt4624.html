Post by Gratch06 » 2003-08-07 23:51

andersz wrote:1. a Music Library like Kazaa (not so heavy) were i can have all my files like napster with a little music player in the program.

Understandably, many people don't use DC++ for the mp3 downloading and DO use it for other purposes. Although MP3 people are a large chunk, I really don't think it merits inclusion based solely on that. Though a player would be nice, any MP3 player with a music library (MusicMatch Jukebox is a fairly easy one) would beat the limited features that could be offered in a combination p2p/mp3 player application. Just my two cents, I found the player in Kazaa totally worthless and used my real MP3 program instead.

andersz wrote:2. an option so i can open for example a mp3-file i am going to download in DC++ instead of going to the map were the file is and the start the file from there.


If I understand you correctly, this is currently available through your finished downloads --> double click filename. As a better fix (and something I intend to do at some point) is that if you open your own file list (perhaps add an "Open My File List" option to the menus), and double click a file, it will load up in the default player/viewer. NOTE: this behavior would ONLY apply if the file you opened was YOUR list. This would work obviously only for files that you had in your share (ooer! a perk for sharing ).

Also included in this is the limit to only being able to play files that are not currently being downloaded (no playing partial files).

Downside to implementing something of this nature is that it encourages people to share incompletes (so they can play the file right from the program).

My two cents. If someone has implemented an MP3 player into DC++ already, I'd be curious to see it.

-Gratch06
