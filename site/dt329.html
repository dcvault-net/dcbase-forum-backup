DC++ is a client and it wont run scripts. You need scripts only when you run a hub.

With hub you should put the scripts to "Scripts" folder under hub installation folder (usually C:\Program Files\Direct Connect Hub\Scripts).

There are lot of documentation about VBScript in internet, try http://msdn.microsoft.com/scripting/.
