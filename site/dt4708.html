Post by distiller » 2003-08-13 02:06

Did you miss TheParanoidOne's post: "Are you aware of the "Automatically search for alternates" option?"

Dc++ does search for alternates on it's own if this option is activated in the settings. You don't have to search yourself... If you want to add new sources for all files I propose this solution:

Do a regular "search for alternates", download the lists from the one's that has the file, select "Match queue". That way all the files you have in common will get the new sources, and you will not have to search for the other files.

Please understand that searches is a huge problem (bandwidth) for the hubs and any feature that will increase searching will likely not be accepted. Features that decrease searching might be implemented though. =)
