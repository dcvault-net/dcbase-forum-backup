Post by Sedulus » 2003-11-30 04:31

TheParanoidOne wrote:
Deathbliss wrote:Or better yet a search option for all image extensions!

AFAIK, not possible with the current protocol. There can only be eight "types" of thing.

yes and no..
TheParanoidOne is correct when saying "the current protocol".

BCDC++ has already stolen the ninth number for (TTH) hash searching.
in theory, there is no problem assigning an nth number for image files. in practice though, it will mean that you'll only get responses from clients that support that nth number (which in the case of BCDC++'s hashing search is no problem, as no other clients would respond to a hash search anyways, while other clients will respond to an 'any'-search with 'bin' as one of its arguments)
http://dc.selwerd.nl/hublist.xml.bz2
http://www.b.ali.btinternet.co.uk/DCPlusPlus/index.html (TheParanoidOne's DC++ Guide)
http://www.dslreports.com/faq/dc (BSOD2600's Direct Connect FAQ)
