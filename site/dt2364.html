Post by GargoyleMT » 2003-04-23 19:40

A Java hub won't work unless you've got shell access - Java can be served by a web server, but the server itself doesn't run/interpret content (except for server side scripting languages like ASP and PHP - you can't run a hub on one of those). If you had shell access on a server that was supposed to allow services, you'd be running one of the unix based hubs already.

So yes, the proper answer is: no, you can't do what you want on the resources you have available.

Post by ButterflySoul » 2003-04-23 20:15

Actually, if you're looking to run your hub on a dedicated server hosted somewhere in a facility, I would suggest you give an eye to small cheapie racks first. A DC hub is not very straining compared to huge website of large corporations, so even something cheap (relatively speaking) might do.
It's typically cheaper to hand over the server with your own stuff on it and just rent out the connection (and lill storage space) than to rent the whole server. If you plan on having your hub run for a few more months, it might be worth the original investement.
The even better part of it being of course that if it's your own server, you can run and install whatever you like on it, instead of having to deal with pre-made pre-installed packages that are typically done for web servers / databases / online catalogs/ordering, etc etc and not really adapted to running a dc server (which typically need a lot of bandwidth and ram, but not as much CPU as a corporate web server).
-You'll find a huge price difference from one place to another, as it's not a common order; so some resellers may have good deals and know the right places while some other will be clueless. Do some comparison shopping first-

Post by ButterflySoul » 2003-04-23 21:43

At $50 for a complete server, the price is definitely great; but it's a 4U. Racks come in different sizes : 1U, 2U, 3U, 4U, 5U, and 7U. Essentially, a 2U is twice the height of a 1U, etc etc.
I'm sure you'll understand the hosting company will charge you more to rent 1 connection and 4 racks as what they'll charge you for 1 connection and 1 rack. How much that difference will be depends on whom you give the server to, but no matter where you go, it's usualy better to pick up a 1U or 2U
At some point, you will need to match the price & size of your server with what the "storage" building will charge you for the connection and the racks, and find the best combination. If there's no monthly price difference in between renting a 1U spot and a 4U spot, then go for it... but more likely there will be.
