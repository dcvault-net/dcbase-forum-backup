Any way those can change back to what they used to do?

Post by Sedulus » 2004-02-01 23:03

+banuser -> use +bannick for offline users
-userinfo -> use +userinfo for online users, and +log nick (simplelog) for offline ones
-history -> use +log time (simplelog)
+ipinfo -> was +lookupip, you want -ipinfo, use +log ip or +log net

> We liked that it banned both the user and ip even if it was offline
.. no it didn't .. it only banned by nick because OpCom doesn't know IPs of offline users. I removed it so it would not _seem_ like it ipbanned the user as well.

> non-OpCom
only OpCom, SimpleLog and OpComExtra provide a bot-interface. I didn't find it useful to add that for other plugins/scripts.
