HubRules-Readme.txt wrote:-- HubRules 1.2 (20030815)
* Changed DCppMinVersion/DCguiMinVersion to DcppMinVersion/DcguiMinVersion and
CheckISP to CheckIsp in the xml settings!
* Fixed a bug that would crash the hub on +plreload HubRules if you use nick
checking
* Added QuickDC tag recognition
* Added NMDCv2 tag recognition
* Added tag recognition for unknown clients. Suggested settings are:
set Strict to TRUE and AllowUnknownTags to TRUE as well. This way you WON'T
allow clients without any kind of tag between angle brackets, but you WILL
allow new clients which adhere to the "<ClientName V:....>" style tag (and
the creators won't have to implement options to fake being a different
client)
* Moved nickchecking to onValidateNick to save bandwidth for denied nicknames
and added RejectMessage (because the motd is not sent this early in the login
process) in which you should specify what naming rules you have
* Added zSearch allowance. With AllowActiveZsearch you have the option of
allowing search bots with a "zSearch[whatever]" (usually
"zSearch[MoGLO]") nick to do one active search before/without sending MyINFO.
Of course only the IPs allowed by DCH++ may do this
* Added +rules/+network/+faq/+sendrules which you know from OpComExtra
