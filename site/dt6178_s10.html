Post by GargoyleMT » 2003-11-16 16:49

Ferus wrote:None SDK needed at all? let's say WinXP and VS .NET 2003 does not need the SDK? and still it's possible to compile DC++, then why has the 0.301 (VS .NET 7.1 version) "compile.txt" the SDK platform as a criteria to have it compile?


Because you do need one. However, Visual Studio always comes with a Platform SDK. Visual Studio 6 shipped with one that was missing features DC++ needed. Visual Studio 7/.NET's is up to date.

compile.txt wrote:3) Make sure you have a fairly recent platform sdk (November 2001 or newer has worked for me)
The sdk is freely available from ms: http://www.microsoft.com/msdownload/pla ... sdkupdate/
You need the core sdk at least (not the 64-bit edition...)
Make sure that this sdk is included _before_ the standard vc directories.
