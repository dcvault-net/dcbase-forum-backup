Post by ButterflySoul » 2003-02-23 19:54

There's many hub softwares out there, and if you know how to write in pascal, LUA, or C++, there are a few that might turn out better for you than the standard from neomodus.

If you don't know any programing language, then the easiest would be to use the Hub Software from NeoModus (you can download it here).

Before installing the hub software from neomodus, you also need to install the client from neomodus (which you can download on the same page)

If you want to give a try to writing your own scripts, give a look to the VBS command reference and the very good tutorial from Microsoft which you can download here. It's the tutorial I actually used myself to learn the basis of vbs. Took me about 2 mornings and a few cups of coffee =)

If you don't feel like writing, or even editing your own scripts, you can check what others did so far and run a script someone else wrote. In this case, have an eye to this thread of the DC++ forums which has links to most of the DC script libraries around (not sure why no moderator made the thread sticky; it could definitely help... oh well).
