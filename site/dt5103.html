This will be brief, so apologies for incomplete sentences.

  • Computers locate each other using IP addresses. eg. 1.2.3.4
  • Humans locate things using words ("domain names"). eg. hub.no-ip.com
  • DNS (Domain Name Server) does a conversion between the two.
  • If you have a static (fixed) IP address and you register a domain name, the two will always correspond.
  • Typical ISPs give you dynamic IP addresses though, so the mapping will only be valid until your IP address changes.
  • With a dynamic DNS service such as no-ip or DynDNS, your register a name such as hub.no-ip.com.
  • They give you software which will update the DNS records every time your IP address changes.
  • You can now use just the domain name without worrying about whether or not your IP address has changed.


You can register for the service by going to the relevant web site such as www.no-ip.com and www.dyndns.org and following the instructions there.

Let me know if I have answered your question of if you need further clarification on any points.

There is some info about the dynamic DNS service at the following thread:
http://dcplusplus.sourceforge.net/forum ... php?t=4932
Most of it is beyond what you are asking here, but there is some pertinent information there.
