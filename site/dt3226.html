  1. Share some stuff (Settings -> Sharing).
  2. Get an updated public hub list (Public hub list icon -> Follow the instructions given).
  3. Connect to a hub (Rick click on a hub in the public hub list and choose Connect).
  4. Start downloading by either:
    My 4 step guide to DC++:

    1. Browsing a users file list.
    2. Using Search

I also suggest that you do the following:
* Read the ReadMe file
* Read the FAQ
* Search the forums for any problems you may have.

Once you have done the three above you will most likely have found answers to all tyour questions. If not, come back here and ask away.

Good luck
