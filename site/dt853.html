Re: I really need these new features!

Post by sarf » 2003-02-12 20:38

GG wrote:[more explorer-look-alike interface]

Convince arnetheduck to consider directories as files in the download queue and you should have no problem. Be more specific. Give solutions.

GG wrote:* The search for "username" option.

This function already exists in MoGlo. It is more fitting for it to be in a search application for DC than in DC++. I, for one, prefer my programs to do a number of things good instead of doing many things badly. As far as I've seen, MoGlo works beautifully as a search application for DC, and it is easy to use MoGlo to search for people and things. Better for it to be seperated, easy to use than incorporated and buggy... as arnetheduck certainly won't get more time available to use for this feature.

GG wrote:* In the download queue list, instead of "set priority" lowest to highest, could'nt we have numbers? 0 is pause 1 is lowest, and for instance 100 is highest?? only 5 options are too few!

And would all these one hundred alternatives be presented as they are now? Should a few presets exist? User specified or hardcoded? Perhaps with a "Set priority to..." menu-choice? Be specific, otherwise you will not get people interested enough in your feature to get off their backs and code it for you... as you are trying to convince people to do work for you.

Last but not least, motivating people to do things will make those things happen sooner than whining about them, something few people discover, especially bosses and managers.
