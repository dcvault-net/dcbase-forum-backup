Post by OrangeSlice » 2004-01-11 00:23

File integrity is indeed a huge problem. I occasionally use zDC++ (a multisource client using dc++ core) to get anime episodes and there is definitly a chance of file corruption when using multiple sources for one file. I would strongly suggest NOT using multisourcing clients to download large files like ISOs and such where file integrity is very important. Its ok for vid files though unless the file really gets messed up and does not play, thats happened to me about 4 times now, normally you usually just get more artifacts in the vid that usual when multisourcing.


Also, some hub operators dislike multisourcing clients as they take up a LOT of user slots when downloading. So, be careful if you use a multisourcing client or you might get banned.


link to zDC++ http://xoomer.virgilio.it/popslutor/

The author is Italian but there is an english version of the client also.
With multisourcing, my 220kB/sec downstream is usually maxed on any file I download, its nice but DC definitly needs some kind of file hashing scheme like BT has.
