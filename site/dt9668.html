Disconnect multiple users from the same IP?

Post by FlameStrike » 2004-04-20 12:05

With the addition of the IP display, I've discovered that I've had more than one user on the same IP downloading files from me at the same time. This prevents other users from other IPs from getting a slot, and I've taken to disconnecting them when I see them, however, I'd like to see a feature implemented that prevents this from happening at all.

What do others here think of this?
