First Looks at the ADCH++ Gui

  • Quote

Post by Toast » 02 Feb 2009, 10:49

I wanted to do an article about the work on ADCH++ thats been going on in the background, the gui is made in Python according to Jacek Sieka (arnetheduck) wishes and its not out yet so there is no download links and its not available for public testing we will report on it when it comes out.

The lib being used is pyQT and the developer thats making the gui is Sulan, he also made some sample scripts in our forum for those that wish to pick up and help out, we really hope he makes more examples and post them.

Well lets get down for the gui stuff:

The first screen is on About Screen

The second screen is General Settings

The third screen is User registration


General commands like kick and ban etc will be done via scripting as well according to Jacek Sieka (arnetheduck) so far ADCH++ takes the largest amount of users but it has the least functionality but we hope that Sulan changes that and makes sample scripts for users to learn from.
