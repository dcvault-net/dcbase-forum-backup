Post by Todi » 2003-12-30 17:53

Before doing something as advanced as running two hubs, perhaps you should learn something as simple as connecting to a hub running on a different port?

You need to connect with the port number, like so: my.hub.com:412
If you don't include a port number, DC++ will assume you want to connect to 411 which is the default port. You don't need to use 412 either, you can use any port that is not already occupied. (Just make sure you use the same one for the hub and the client connecting to it)
