Post by Saurod » 2003-11-29 07:52

#1 - A way of turning off autosearch for whole directories or groups of files, so autosearch could focus on what you REALLY want.

You can turn off Use default search strings in auto search when no string is specified. Then you will have to set the search string for the things you really want. You can also pause the downloads you're not that interested in.

#2 - A gui solution to autosearching rar-sets, like a field which displays
search string when multiple files are highlighted and groups them to one search instead of ten. This is possible now by deleting searchstring in 9 out of 10 files i guess, but not really easily manageable.

I've definitely been thinking about it. I will implement it, sooner or later...

#3 - A way of telling how long a full rotation of autosearches through filelist will take, which should be easily calculated. Maybe even a log-option for searches and results? Might be a little much, but it could be useful.

Not going to happen. There is no full rotation except in very special cases. I can tell you this- there will be at least 60 minutes between searching for the same search string again, but there's no guarantee that a specific search string will be searched for at all! It's random.
