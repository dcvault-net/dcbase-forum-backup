Post by ButterflySoul » 2003-03-01 12:31

I don't think any script currently offers what you describe in reg - all
I'm not sure of the point of registering all the people in the hub, since it would mean that you would need to run the hub unregistered for a while anyway ? The users not in the hub at the time you type the command would be unable to access the hub later, when you switch the hub to "allow only registered users"

I would suggest using Aphrodite for example, which allows users to self-register, and to change their pass. That way, you can put up an announcement upon login for a week, and warn all your users that they need to register themselves because in x days, you'll switch the hub to registered users only.

You can find Aphrodite on DCStats (one of my fav scripts =)
