Ok, I'm tired of asking the same questions over and over again for the posts in the Help forum. So I propose to create a standard set of questions that should stop us from having to ask the same shit over and over again. Is there any way to force users to read a link before posting? For example here: http://www.dslreports.com/forum/sitehelp when you click on New Post, it forces you to read another page of commonly asked stuff before continuing on with posting....

If there is not a way that can be implemented, then having a sticky at the top of the forum that the users will hopefully use/fill out (or we can simply paste into a post) will be the only other way to go. Here is a list of questions I've come up with so far...

1) Have you read the FAQ?
2) What version of DC++ (that includes DC++ mods too!)
3) What Operating System ?
4) Any software firewall? If so, the name / version
5) Any routers/modems? If so, the brand / model / firmware
6) Internal IP address ( Start | Run | CMD | ipconfig ) [sensor the last two octets if it matches your public IP]

Post by Todi » 2004-06-14 17:58

IMHO, a sticky won't help. They already ignore those. But maybe force them to read it if they want to post (or start a thread) in the Help/Support forum? That should minimize the impact on "regular" users, and increase the chance of the ones wanting help reading it. However, If we're gonna do it like this (which i think would be good), we need to lower ourselves to the users level

Suggested wording (i can work on it some more later, but in this direction):

1) Have you read the list of Frequently Asked Questions? Perhaps your questions has already been answered there.
2) What version of DC++ are you using? (that includes clients based on DC++ also, so called Mods/Clones)
3) What Operating System are you using? (Usually a version of Windows, like 2000 or XP)
4) Do you use a software firewall? If so, please specify the name and version.
5) Do you use a router or a modem to connect to the internet? If so, please specify the brand / model / firmware if you know it.
6) What is your internal IP address (in Windows -> Start button | Run... | type "CMD" (or "Command") and press Enter | type "ipconfig" and press Enter) [sensor the last two numbers if it matches your public IP]
7. Are you in Active or Passive mode? (Check your settings) If you are active, try using Passive mode, does that solve your problem? (for testing purposes only)
