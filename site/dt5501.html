Hubslot ratio dependant on the user specified connection type is pointless IMO (and not implemented). Since the user can set it, it becomes worthless when trying to enfoce a hubslot ratio.

The language files should be included with the files you got. If not, get a previous version, they're in there.

The path for your hubrules probably isnt setup right. I've got: <Rules MinLevel="0">texts/rules</Rules>
and it lives in C:\Program Files\dchpp\config\texts
