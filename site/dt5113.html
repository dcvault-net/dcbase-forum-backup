hi here is breif help to get you started, running a hub!

ok, you want to start a no-ip account so your hub has a server!

1, go to www.no-ip.com and set up a free no-ip account!
remember to wright down all passwords and what e-mail address you use incase you have lots.

2, somewhere on that site you will be able to find something called d.u.c 217, or simuler depending on if its been updated!
When you start the d.u.c up you need to enter the e-mail and password you use for no-ip in edit at the top then make sure that you can see your server host name in the window eg:---> myhub.no-ip.com, if you can see tha your nearly there!
all you should need to do is check the box at the side of your host name(myhub.no-ip.com) to make sure that the server is picking up the duc, once the face smiles at you on the duc (look you will no what i mean) its working and you can now start your hub!
