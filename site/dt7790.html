Searching filelists

Post by pweddell » 2004-01-24 17:47

Following http://dcplusplus.sourceforge.net/forum ... php?t=7210

I want to search UNOPENED filelists for all users that have a particular file or folder. ADLSearch only works for files you open - either from your hard drive or from the remote user (ie download). Whilst a filelist may not accurately reflect what the user is currently sharing (it could be 1 minute out of date, for example) most users should have the request offline and will load it if requested. MS Word can search files on the hard drive for specific text.

Users that are currently offline at "this minute" come online again later. So, you can add a file to your download queue and it will be downloaded when the user comes online. It is quite laborious to open each filelist individually to browse through and find something that interests you.

Files can be found under several users but search for alternatives won't always work because the file can have a slightly different filename. Therefore a manual search is required as what the user wants won't get added to the download queue. OK perhaps a request should be made for a fuzzy search but match queue won't work either if there is a slight difference in the filename.

If you do use Match Queue the program assumes (as the name of the function naturally implies) that the file you want is already in the queue. But if you want to see what else the user has you have to manually open the list. ADL Search and Match Queue don't work together! So if the user has something else you want you need to browse through his or her list to find out if there is something there that you want. OK, perhaps trivial, but if you already have their list on your hard drive how much easier it would be to search the drive.
