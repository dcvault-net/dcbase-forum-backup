Post by TheParanoidOne » 2003-08-31 23:44

If the headings have are not visible, they have somehow all been set to width 0.

To fix it, do the following:
1. Close DC++.
2. Open DCPlusPlus.xml in notepad.
3. Find the line containing <SearchFrameWidths> and remove it.
4. Save and close the document.
5. Reopen DC++.
6. Search for something and report back here if it works.
