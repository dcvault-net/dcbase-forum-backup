Configurable upload slots

Post by Kunda » 2003-02-02 00:42

I added the following comment to a suggeston in the feature tracker only to realise it had been closed (rejected). Does this mean we will never be able to set conditions for our open upload slots? Maybe this should be the subject of a poll..?
Yes I hurriedly opened the settings dialog after I got 0.22 expecting to see a CONFIGURE button next to "Upload slots" in the Sharing tab... just empty space *sigh*

Would it be that hard to have a dialog appear with "Filetype" and "Filesize" dropdowns next to EVERY upload slot, with the default settings "*.*" (filetype) and "Any size" (filesize)?

That way the slots will behave as they do now unless u chose to change them.

The Filetype dropdown list could be editable having Remove and Add buttons, and radio buttons to choose either "Only these filetypes" or "Every filetype except these"

The Filesize could have 2 uneditable dropdowns next to eachother - first just having "Any filesize","only files over", "only files under", and "only files between" which would affect what is in the dropdown list of the second - disabled for "Any filesize", a set list of sizes for both "..over" and "..under", and a set list of size ranges for "only files between"
.. the second one I guess could be editable (with an optional 3rd dropdown for gb,mb,kb,bytes) as long as there is appropriate abuse checking to prevent ppl entering numbers too small or big.

There should also be a check to enforce at least one slot to be kept at the default setting.
