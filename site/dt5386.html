Post by Twink » 2003-09-22 11:23

there are problems with your idea, and they have all been pointed out before if you cared to read other forum posts.

If a person is downloading with another program during this test then their speed will be capped lower then it should be

if the server is getting overloaded or the user has a faster connection then the server the program will cap the speed lower then it should be


sometimes there are reasons to cap speeds, which I'm sure you agree with, most clients that have speed caps also enforce some kind of ratio or limit the download speed if the upload speed is limited too low. sometimes it can be handy to limit uploads and downloads to a low speed for a period of time when u need bw for something more important, this is better then closing the program in some cases as no slots are actually lost.

anyways there are lots of other points outlined in other posts on the forums about this topic, I suggest you go reading.
