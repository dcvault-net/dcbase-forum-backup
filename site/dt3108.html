new version to be released soon

Post by seer_tenedos » 2003-09-30 21:27

A new version of our DC client sharpconnect will be released on the 10/10/03. Note that we are still an alpha client but here is what we intend to have working by the release date.

- config screens
- downloading public hub list
- adding private hubs and been able to configure existing ones
- all chat and search functionality
- been able to connect to one or more hubs.
- private messages
- transfer from one hub to another when the hub tells the client to
- stable connection to the hub (except for getting kick for fake share at the min or not replying to searchs)
- basic plugin system
- updated GUI

Chnages that may be in this release or next release depending on time
- dynamic detection of local ip
- dynamic detection of internet ip
- improved plugin system.
- support incoming search requests
- support file uploads (with possibility to cap upload speed)
- support multi source file downloads
- basic file queue plugin (same as current DC++)
- advance file queue plugin (this will be in next release not this one and the details on the advance file queue will not be release to a later date as they are still changing. this queue is focused towards advance users that need more power from their download queue and to leechers that have gigs of files queued and what soem files before others but find that the current file download queue in DC++ is to restrictive)

The website for the project is http://sourceforge.net/projects/sharpconnect/ for those interested in having a look. Please not that the current release for downlaod is not really a good release as it does not connect to servers very well. You would be better waiting for the next release on the 10/10/03.

Alos if you are a C# coder and want to join our project let me know. We can always use a few more good C# programmers.

Chris
