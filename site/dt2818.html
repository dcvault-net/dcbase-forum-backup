Post by distiller » 2003-05-15 23:48

You can add multiple sources to the same file. DC++ will download from the one that responds first. DC++ also checks if the size is the same, if sizes doesn't match you can never add that sourc to the queue item (no use really).

This is a good way to add sources to a queue item:
Right-click a file in the Download Queue, select "Search alternate...".

If you recieve results from the search in the new windows, sort them by size and select all that have the corerct size (the filennames CAN differ!).

Rightclick anyone of the selected alternatives and choose "Download To". If you have a queue item that has the same exact size as the selected sources there will be an alternative, select it.

If you have "test.avi" in your download queue, and do a "Search for alt." and found 3 results; "testing.avi, atest.avi and test2.avi" which all had the same size, select them - use shift, left-click first item, then last while still holding shift, then release shift.
When you right click one of the select item and choose "download to" you will see your "defaultpath\test.avi" there, fxp "D:\downloads\test.avi", select it and DC++ can now use any of the three sources for this queue item.
