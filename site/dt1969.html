Post by ButterflySoul » 2003-04-08 01:40

When you install the Hub from Neo Modus, there's already a Scripts directory, and it already has some files with the .script extension in them. If you want to add additional scripts, just drop them in that directory and they'll launch at the hub startup.

Most of these scripts are in VBS, so they're for the neomodus hub, SBHub and RDCHub. You'll find a few ones in LUA, those are for Ptokax (and DCH++ when it gets released)
