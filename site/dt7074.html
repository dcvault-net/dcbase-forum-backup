Hublist problems

Post by TheParanoidOne » 2003-12-19 12:36

Ever since the hublist.org hublist became the default one, I have seen flurries of "I can't access the hublist" whenever hublist.org goes down temporarily. It would be useful to have one thread to point people to, with an explanation of why the hublist download failed as well as the solution, ie. a number of alternative hublists.

I know that one such thread already exists here: http://dcplusplus.sourceforge.net/forum ... php?t=1723
but that thread was initially created for a slightly different problem (SF being unable to supply the hublist) and also contains a number of dead lists.

I propose that one of the following be done:
A) Unsticky the old thread, let it disappear into oblivion and create a new one (locked and sticky).
B) Keep the existing thread, removing all posts except the first, and updating the list of hubs.

I personally prefer A because the existing thread has become quite messy.

Whichever way is chosen, we would regularly update the initial post by adding new lists and purging dead ones.

Thoughts?
