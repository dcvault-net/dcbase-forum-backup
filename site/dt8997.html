Absolute & Porous DL Slots

Post by Seisled » 2004-03-25 19:14

I didn't find a thread relating specifically to absolute & porous DL slots, so I thought I'd mention it even though it is a little obvious. If it were possible to set an absolute limit on download slots in addition to the porous limit I believe it would be useful.

For instance, currently I have the porous limit set at 20 and this is well-surpassed after a short while because I have a substantial number of DLs set at highest priority. This is what I intended, however, when the total DLs exceed 50 at a given time, then the speed obviously goes down quite dramatically on each DL. So, if it were possible to set an absolute limit on DL slots (that DC would not exceed under any circumstances based on DL priority) in addition to the porous limit then I believe it would be useful in situations like the one I described above.
