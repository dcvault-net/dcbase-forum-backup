DSHub - Adding Anti Spam Protection

  • Quote

Post by Toast » 25 Mar 2008, 14:41

Anti Free DNS Spam

Use Flag 202 for these so it checks main pm etc

!chatcontrol add "regular expression" 202

Here is for .org

Code: Select all

\.(hopto|myftp|no-ip|zapto|blogdns|boldlygoingnowhere|dns(alias|dojo)|dvrdns|dyndns|game-host|(got|home)dns|home(ftp|linux|unix)|is(-a-chef|(-)?a-geek)|kicks-ass|podzone|selfip|serve(bbs|ftp|game)|free-bsd|freens|igger|linsucks|nailed|nofw|ods|us-the-bomb)\.org(:\d{1,5})?
Here is for .biz

Code: Select all

\.(myftp|no-ip|dyndns|selfip)\.biz(:\d{1,5})?
Here is for .com

Code: Select all

\.(myvnc|serve(beer|bbs|counterstrike|ftp|game|halflife|http|mp3|pics|quake)|blogdns|dns(alias|dojo)|dyn(-o-saur|alias)|getmyip|gotdns|hobby-site|homelinux|homeunix|is(-a-chef|(-)?a-geek)|selfip|resolveme|inetgames|netbounce|vdirect|dtmxchange|phathookups)\.com(:\d{1,5})?
Here is for .net

Code: Select all

\.(redirectme|serveblog|sytes|blogdns|dns(alias|dojo)|dynalias|ham-radio-op|home(ftp|ip|linux|unix)|is(-a-chef|(-)?a-geek)|kicks-ass|podzone|selfip|serve(bbs|ftp)|mydyn|emailme|getto|netbounce|oneaddress|snapto|vdirect|webrally|ftphost|igger|linsucks)\.net(:\d{1,5})?
Here is for general DCHub Spam

Code: Select all

([Dd][Cc][Hh][Uu][Bb]|[Aa][Dd][Cc])://((25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.(25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.(25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)\.(25[0-5]|2[0-4][0-9]|[01]?[0-9][0-9]?)|\w{2,15}\.[a-zA-Z]{2,3})(:[0-9]{1,5}$)?
Here is for HTTP Spam

Code: Select all

(w(\s)?){3}\.(?:(\s)?\w(\s)?){3,15}\.(?:(\s)?([CcOoMm]|[SsEe]|[NnOo]|[FfIi]|[DdEe]|[NnEeTt]|[OorRgG])(\s)?){2,4}
Here is for Email Spam

Code: Select all

[_-\w]{1,25}@\w{1,25}(\.[_-\w]{1,25}){0,3}\.[A-Za-z]{2,4}
