Post by Borlag » 2004-04-20 01:39

Wisp wrote:Another example: I have a lot of albums and sometimes a specific track appears on a normal cd and on a compilation cd, dc++ first sees the compilation cd and then removes the tracks from the other cd, if people search for the cd and rightclick>download whole directory, then they download an incomplete album
(i know: this happens only if users don't know about the option to disable removing duplicates, or forget to disable it)


Poor example really... I've tested this myself and if the files have different mp3 tags, for example one says Band this and that - studio album a - song b, and other says Band this and that - compilation b - song b. They're considered different files by the TTH hashing even if same filename and filesize because the contents are different, even if only by few bytes (the actual tag).

Besides, if you're sharing music, keep the tags correct...personally I absolutely hate having to fix them if someone hasn't made them or if they're wrong...

As for that installed vs. install directories...poor argument also. If you share them in a .bin or .rar format, the person who is downloading from you will get every file needed for the installation, and provided your file is good, he or she will get an uncorrupted file, thus there's no need to download single files because it was never corrupted in the first place.

If you'd share the install directory, you'd have literally thousands of files at the worst case scenario, and that way it would be very easy to miss some file and thus the installation pack wouldn't work. Also in your example you used Windows installations as your example, it's a moot point since if windows installation is missing a file or a file is corrupt, it will ask for a specific .cab file that contains the actual file needed. Rar packages of those in maybe 5-10 cabs in one aren't much to ask really as most hubs with any kind of sharechecking will boot you for sharing installed if you have any .ini or .dll files, not to mention the other possible files you'd have when sharing windows.
