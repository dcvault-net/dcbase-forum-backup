Active mode means that other will be able to connect to you, thus you can not be in stealth mode. In passive mode you have to initiate all comunication thus you can be in stealth mode.
As for being in danger, if you have a software firewall (you should anyway to prevent unknown applications from accessing the network) it should close the port when DC++ isn't running and now you would be in stealth mode (while DC++ is closed).

Post by Naga » 2004-03-23 17:19

Active mode means that other users can connect to you to get files, while in passive mode you have to connect to all (both to get files and to those who want's to download from you) thus you can't download from other passive users. In active mode you get search results directly from other users while in passive mode all search results go thru the hub (you connect to the hub when you go online) and this is not liked by the hub owners (too much bandwidth). In short if you can be active, passive is a if nothing else works solution.
