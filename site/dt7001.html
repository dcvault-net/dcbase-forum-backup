Post by ivulfusbar » 2003-12-16 09:56

oohh yes, another follow-up on the subject. In the protocol you can search in the following ways, "Normal (no size restrictions)", "Atleast size", "Atmost size". Some also support a more or less hackish way to send "Exact" size. It is not possible to search for between size x and size y on outgoing searches. So replying clients might endup never answering with matches between x and y. Ofcourse your client can filter the responses and only adress the once between x and y.
