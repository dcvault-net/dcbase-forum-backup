Step By Step

Post by GOLIATH » 2006-09-26 15:25

ok this is how I was explained on how to compile a client,
  1. Download the source
  2. Unzip the source
  3. Click on the file named "RunMe-then-DeleteMe.bat"
  4. Go into the folder marked Docs and Stuff/Bats
  5. Click on the file named "RunMe-then-DeleteMe.bat"
  6. Click on the file named "add-includes.bat"
  7. Click on the file named "build-beta.bat"
  8. Wait a while and you should have a new client all ready to start up in the folder named "app"
