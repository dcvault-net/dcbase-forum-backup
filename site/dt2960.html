Post by sarf » 2003-05-24 05:47

OLDoMiNiON wrote:I'm curious sarf. Why did you get rid of the useful OP-like tools in DC++k?

Well... some of them was incorporated (well, kinda...) into DC++ (custom commands), and the others were quite instable (not to mention a pain in the neck to add back into DC++ all the time). Also, there are people which are working on tools that do the same thing as DC++k did before - I'll probably snatch the code from then and tinker a bit with it when they are done. That way I can hopefully get a more stable version of the "OP-tools". Something I have been thinking about is an automated filelist/share size checker, but that's still on the drawing board.
