The perfect file sharing program...

Post by sauroneru » 2003-09-07 18:24

I know a lot of this has been discussed, but I wanted to share my idea of the perfect file sharing program. I firmly believe these minor modifications would both reduce traffic and make downloading much easier, if properly implemented.

1. Start with DC++.
2. Identify each shared file with some unique identifier that would be the same for others' computers, such as an MD5 checksum.
3. When I search for a file by name, I can right click on it and select "auto-download", which would automatically find all files the same size and with the same unique ID.
4. The "autofind" would repeat itself maybe once an hour, or whenever I don't have any more sources to download from.
5. Add multi-user / multi-thread / whatever you want to call it downloading to the mix.

I've seen all the controversial multiuser downloading topics, but I really believe that the above system would reduce traffic. Right now, I'm downloading a 700 MB file from about 6 different sources. I have to do this to have a chance to get one to stick around long enough to get a good download. I know I can place them all in the same queue, but if the user I choose to download from drops speed, then I'm screwed unless I'm paying careful attention the whole time. I admit to wasting traffic, although I also make sure my total up/down ratio stays over 1.0. If the above system were implemented, new users would be automatically added to the mix and I wouldn't waste any bandwidth. It would be pretty darn efficient. I'm sure someone else has thought of putting these two basic ideas together before - is there a reason this doesn't exist in DC++ or any other program (that I'm aware of)?
