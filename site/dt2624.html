Post by Sedulus » 2003-05-06 02:47

you'll need a couple of things:
- a computer/server
- 24/7 internet
- 0 byte minshare
- enough files
- some trusted people as ops, to remove users with illegal shares (though not absolutely necessary)
- a piece of hubsoftware (until DCH++ is released, I'd suggest PtokaX)
- a teensy bit of knowledge to set the thing up
- a fixed (static) IP or a dyndns-service
- be able to use the search function (in the forum of the software you decide to use) when having problems with setting up the hub (no pun, no offence)
http://dc.selwerd.nl/hublist.xml.bz2
http://www.b.ali.btinternet.co.uk/DCPlusPlus/index.html (TheParanoidOne's DC++ Guide)
http://www.dslreports.com/faq/dc (BSOD2600's Direct Connect FAQ)
