ok a few things to note....

Don't use it in conjunction with other Plug Ins (if any one knows how to correct this plz tell me, or correct the code for me )

Made it so +UserInfo only works for OP's

in the txt file iv made it so you can add comments using //

in the text file DO NOT leave a blank line (i think it might course it to crash but not tested it yet, so better to be safe than sorry )

Added the option to redirect people that are below a certain amount of bytes shared ( you do this be setting things in the text file)

At moment in time both ops and regular users get redirected to where ever u specify (in the text file) if they are not sharing enough.

Fixed the bug for when it crashed if u did userinfo and the length of string for the amount they were sharing was less than 2.
