What product family do you think ME belongs to? Since you didn't know, it is the same code base that Windows 95, 98, and 98SE came from. The PSAPI calls I use (which has been changed to a load-when needed in later BCDC versions) are available only on NT based OSes - which means Windows NT 4.0, Windows 2000, Windows XP, and Windows 2003.
