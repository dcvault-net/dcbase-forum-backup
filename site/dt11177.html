Post by GargoyleMT » 2004-07-05 00:53

cyberal wrote:I am aware of that option.. but the file is shown as 0 byte...

That's not how DC++ avoids counting it towards your share size - it merely subtracts the total size of the file from your published share size when it finds a duplicate. If you set the option so duplicates remain in your list, the file is included when making the list (and the file's size is normal in said list), otherwise the filename is omitted from the share.

Post by GargoyleMT » 2004-07-05 20:26

Yup, Todi has it right.

DC++ calculates the share size while making the file list - any duplicates just don't count towards. So, the share size in the user list will not match the total of your list if DC++ is keeping the duplicates in your list.
