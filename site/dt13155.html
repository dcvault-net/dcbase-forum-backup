If you don't want to use vlc you will need some codecs to get the videos running in normal windowsmediaplayer:
DivX5.12 Pro and XviD Koepi 1.0.2 are the codec needed for playing nearevry videofile
you could also use ffdshow instead (this is a filter not a codec but for normal purposes it can replace a codec)

Huffyuv 0.2.2.1 is a lossless codec more useful for prozessing videofiles without dataloss -- so just for watching not needed

mp3 is standard codec for playing the audio but there is also ogg audio and ac3
ac3 codec will be installed from most dvd players so you won't need it.
the ogg codec would be nice if you want to watch ogm-Videos
therefore you might also need some filters (http://www.doom9.org/Soft21/Filters/OggDS0995.exe and
vob-sub as filter for the subtitles (or http://www.doom9.org/Soft21/Filters/SubTitDS1400.exe)

mov files should be played with quicktime, although new VLC can play them really good, codec for playing mov files seem not to work with every file

and there are also videos restricted to realplayer but that is normally nothing you download in a filesharer.

hmm hope I haven't left sth out. (there is also Matroska file but thats a bit rare)
so recommendation --> use VLC thats easier
