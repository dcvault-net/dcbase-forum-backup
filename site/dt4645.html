1. More priority settings is not the solution here, it would just make the queue messy, and are you seriously gonna set 20 different prioritys if you download... say an mp3 album.. no way!

The solution is to make DC++ download the files in the order they are in the queue. And to make DC++ add the files alphabeticly when you add an entire folder (again, mp3 album). This would make DC++ download file 1,2,3,4,5... etc. like it should be... and if you fore some reason wanted to download file 9 after file 2, you can just drag that file and put it after 2 in the list! The NMDC-way!


2. This has nothing to do with DC++ client software. Hubsoftware deals with this!
