TheParanoidOne wrote:Can you give an example of when having just the folder structure but none of the files, is useful?
Couldn't you just examine the folder structure in the other user's file list and just manually create it? Why go through the trouble of queueing it/deleting it?

Well I just had to download a whole range of albums, and after searching I found a user with the right albums in his filelist, it looked like this (fictional names)

So I was glad to find such a neat directory structure with everything I needed.. the only problem was, that some of the albums where in WMA format instead of MP3, so i wanted to delete the WMA's and replace them with MP3's from other users, but because dc++ first downloaded all the small files (covers/lyrics), only the CD1 and CD2 folders where left. When i deleted the WMA files from CD1 and CD2, the whole album directory was gone, which is kind of annoying, cause i had to manually check which albums where done and which weren't. Also I had to manually re-create the correct directories in my download directory, before I could specify them as target directory.

I know it's also possible to first download the MP3 files before deleting the WMA's, but because you expect the same behaviour from the download queue, as windows explorer, you don't always think about that.
