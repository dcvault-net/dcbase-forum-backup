ADL Search Interface.

Post by Kenneth-Chile » 2003-03-23 17:47

Initialy, I didn't know what adl search was. But now that I know this great feature, I believe that the interface to create what we are looking for is not the best at all.

So that you don't believe that only I am criticizing, I made the following proposal for ADL Search Interface:

Above the ADL Status Bar, Create two buttons: NEW and REMOVE (The same way like in the Favorites Window).

When NEW button is clicked, a new form window is opened (like the NEW favorites form). This form contains:

Title bar: "ADL Search Item Properties"

Search String text box.

Source Type Pulldown Menu. Choices: Filename, Directory, Full Path. (Suggestion: If Filename is choosed, it could appear a new pulldown menu with Normal Search Type Choices: Audio, video, any, etc)
Destination Text box. Default string: ADLSearch

Active Pulldown Menu. Choices: Yes. No. (Suggestion: It could change the name to "Connected" if "Active" is what i think that it is)

Min Size Text Box. Besides a Size Unit Pulldown: KB-MB.

Max Size Text Box. Besides a Size Unit Pulldown: KB-MB.


Finally Three Buttons: OK, CANCEL and WHAT IS ADL Search?. This last button open a simple window with no more of 3 lines explanation about what ADL Search is. This will help to increase the use of this great feature, because there are few people who know what ADLSearch is.

Greetings.

Kenneth.
