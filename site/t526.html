The Forum's New Clothes (site style changes recap)

Post by Crise » Tue Jun 16, 2009 3:03 pm

Forums have, finally, received a "new" look that befits them. To commemorate this joyous occasion I have pushed everyone to use this new "integrated" style.

The new site style does not support Internet Explorer 6. Anyone still using that is recommended to either upgrade to IE8 or if that's not possible install either Firefox, Opera or WebKit (Google Chrome, Safari) based browser.

If you do not like the new looks for some (weird) reason you are free to change back to any of the other styles. You can do this through your User Control Panel, there under Board Preferences you'll find a drop down list of available styles to choose from.

For all the subsilver fans. Unfortunately there won't be a subsilver alternative for the new look because subsilver2 will eventually be dropped by the phpBB Teams (and prosilver was actually easier to integrate to the current site layout than subsilver2).

To sum up other style changes that have been taking place site wide during the past week, for those that have not been following the previous news topic. We have received a new larger tab menu and a new overall wider layout which sizes according to your screen resolution.

Sorry for any inconvenience caused by the work done on the site, because it was the cause for several short outages in the past week. Also all users should refresh their browser cache, if the site displays oddly, because some browsers have the tendency to cache CSS stylesheets for far longer than necessary. If even after clearing your cache the site displays oddly or seems broken somehow please report it.

Any further improvement suggestions are welcome as well, though.
