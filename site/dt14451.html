Post by HaArD » 2005-01-10 14:55

Xsthetic NetServer by Hawk uses a very old version of Hub-LInk to provide multi-hub capability.

The built in multi-hub from PtokaX with MHServer is unstable, it will provide a simple multi-hub chat if both hubs are running 0.326TD4. It might even work with the leaked version of .330 B15.25 but don't bother trying with .330 B15.30 it won't work at all.

The MHServer software was never officially released and the source code for the project was lost when aMutex lefvt the PtokaX development team.

Not that I'm biased, but if you want to enable multi-hub chat with PtokaX, use Hub-Link.

If your goal is to somehow hide who is running a server from the system administrators by running more then one of them... well... you are just kidding yourself....
