Search Window Annoyance

Post by lordadmira » 2006-04-22 19:40

I noticed that new search windows retain the type setting from old search windows. According to the change log this is a new "feature". I must say that this is incredibly annoying. I've burned many wasted searches because I didn't notice that the type was no longer "any" even though I was in a new window.

Basically can this feature be removed in the next version? If not can we have an option to disable it. I want all my new search windows to default to the vanilla setting.
