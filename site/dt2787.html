CBZ and CBR are the same as zip and rar, just renamed so CDisplay opens them instead of your file compression program.

I'm opening up this old thread because I was wondering if these two extensions could be added to the compressed file type search filter in the next release. cbz and cbr are pretty much the de facto extensions used by people sharing compressed comics now.

Post by Todi » 2004-10-09 08:17

Yes, those extensions are widely used in the comic sharing community, however they have practically no use to anyone else. Adding additional extensions to the ones DC++ already filters for is usually not a good idea, since it would only increase the usage of resources for everyone. In this case i do not think it would be worth it.

A simpler solution is to simply include "cbr" or "cbz" in your searches, i.e "x-men cbr" and "y the last man cbz", which would give you the same result. Besides, since we now have TTH's to autosearch for, and finally can add additional sources regardless of if the source has the .cbr or .rar extension (as long as the TTH is the same) it works out pretty good in the end.
