Interface (STATUS AREA) Issue

Post by DeathStalker77 » 2004-03-18 21:49

I don't know about anyone else, but I REALLY, REALLY like the interface that oDC had up to v5.212. I WANT my uploads and downloads SEPARATED. I shouldn't think that it would be too much trouble to code an option into DC++ to allow for a better selection of configurations. Could be as simple as selecting between the two and just dropping in the entire interface code from oDC v5.212.

The other thing I REALL REALLY REALLY like about oDC is that it shows you what file is queued up for users who you are waiting to connect to - this GREATLY aids in setting your file priorities!

I'd be indebited to anyone who could look into this issue. I'd love to move up to the new features in DC++ 0.307, but I don't want to lose these features.

Thanks SO much!
