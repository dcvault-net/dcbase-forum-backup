Exact same problem here. DC++ is virtually useless for me right now. The first search goes through without a hitch. Second search is where it gets odd. One of two things happens:

1) The second search won't do anything. No results, nothing filtered, no search spam warnings from the hub. Doesn't matter if its the same search window or not. Doesn't matter if your searching for alternates or starting a new search.

2) The second search will apply itself to the first search. Best way to describe it is with an example. Say search #1 is for "SPEARS" and no filters. You'll get thousands of hits. Start a new search (again, doesn't matter if you use a new window or reuse the current one) with "AGUILERA" and no filters and you'll get around six hits. However, those six hits have both "SPEARS" and "AGUILERA" in the filename.

Its as if DC++ never recognizes an end to the first search. I can walk away for an hour and it'll be the same story.

I have a Belkin router (latest firmware) with firewall on/off, NAT table, DMZ. I've tried turning the firewall completely off, putting my PC in the DMZ, using pure passive mode, uPnP port forwarding, and manual port forwarding. All the same results, first search & downloading is fine, second search is either screwed up or never happens. I have also tried several hubs just in case this was a bug with a certain hub software or a single hub owner that didn't know what he was doing. The Windows SP2 firewall is completely disabled (never use the damned thing). No other software firewall installed. Only thing I haven't tried is removing the router. Don't want to do that. But if nobody offers anything promising here, might do it this weekend.

I would also like to add that I've been using various forms of DC for several years. I know how to set a client up and this is the first time I've ever had a significant problem with DC++. I've owned this particular router for a little over a year, its never given me a problem before and all other software titles are working fine.

/EDIT:

Did discover something else though while retesting. If I am only connected to one hub, I do not have to exit DC++ to search again. I can disconnect form the hub I'm in, reconnect, and I'll get one search.

Also, if I'm connected to one hub, do one search, then connect to a second hub I can do another search and the search will behave normally that one time. I've repeated this process to 20 hubs/20 searches.

So adding a hub resets the search for me. Disconnected from all hubs resets the search for me. Quitting DC++ obviously resets the search.
