Post by GargoyleMT » 2004-08-12 03:45

Pycckuu wrote:Since you tend to ironise here i won`t argue.

It's a bit of sarcasm, but the truth underneath is that it would add a lot to the program size wise to keep flags. You can't have them for all 380(?) or so nations of the world, you have to figure out which to use.

Plus, there is already one graphic in that listview, to add another bitmap/icon, you would need to do a little bit of extra coding to draw it manually.

And many people might recognize the country code before the flag.


If you want this, I'd suggest you program it, or get a friend to. Then submit the patch. It'll either get accepted or rejected. If it's rejected, you/your friend can compile yourself/you a copy with the feature you want.
