sdch has really surprised me, would like to test it with some gadget scripts, but cant find the converter


Just for the record, some of Gadget's scripts have been re-written especially for SDCH. Sure, running their NMDC version thru the converter works just fine, but while SDCH has direct equivalents for each and every NMDC command/object/sub/property, it also has a lot of new ones that allow more powerful scripts... Running a script that was designed especially with SDCH's capabilities in mind will generally run better than a converted script using NMDC's limited options, eventhough in terms of pure functionality, both will typically bring the exact same end-result =)

You will find some of these scripts in the SDCH forums. You'll also find a few over there :
http://sourceforge.net/tracker/?atid=54 ... unc=browse
