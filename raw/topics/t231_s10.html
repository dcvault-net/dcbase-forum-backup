Post by en_dator » 09 Oct 2008, 17:40

after having tried to make bot output look nice on the screen for quite some time I have to say that I now more and more like this idea

these are my opinions:

If compability is intended, then sending client should send the message in two parts, with both formatted message and also message in clear text, that way a client that does not support the flag should ignore the first formatted text (thats how the protocol is designed isnt it . ignore everything you dont understand?) and instead display the second clear text message. A client that supports the flag displays the first formatted message and knows to ignore the second one sent in clear text.

styles that i would like to see are : underline, italic, bold, text color, bg color, text size (in relative sizes), font name, text align left/right/center, and enable/disable emoticon for current message.

In the client I would like the following options: (i know it aint part of the spec but its related anyway so here it goes)
Allow options for each style option, like
Allow underline yes/no
Allow italic yes/no
etc

for text size I would like to have in addition to allow, also the possibility to set the max and min allowed text sizes.

if the tags are bbcode style or html style I dont care much, but it would ofc be nice if they follow some existing method as that would make less of a headache for ppl (including myself)
