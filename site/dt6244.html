UI: Separate Uploads from Downloads + Minimize to the top

Post by Gorgonzola » 2003-11-15 03:52

I would like to see an adjustable border that separates uploads from downloads. The way it is now, with the current available sorting orders, there is no way to definatly make all uploads always list below all downloads. Instead I often find they mix making the overview of the traffic somewhat messy. For this reason it would be very nice to have separate sections for Downloads and Uploads.

Another disturbing thing is that windows minimize to the bottom of the desktop (inactive grey area/background). This is all good an well until you decide you want to resize the List of current downloads/uploads. If you drag it upwards it will totally cover the minimized windows making them inaccessible. For this reason it would be better if windows minimized to the top of the desktop instead.

Post by Gorgonzola » 2003-11-15 22:12

NecroGrim, very good point about the closeness of the minimized bars and the icons but...

Yes, clicking on the icons themselves works (brings to front) if windows are always kept maximized, with the exception of Search. But clicking the icons when windows are minimized will only make them flash. It would be better then if they would maximize.

Personally I think alot of windows stacked upon eachother looks messy, and I really like to be able to minimize them. Perhaps an option to be able to doubleclick* on either the icons or the tabs at the bottom could minimize windows aswell. That way you would have the same level of control whether you like to click icons, windowbarbuttons or use the tabs below. If there should be 3 ways to access the windows I think they should atleast be somewhat equally functional, otherwise what works where gets kinda frustrating. With equal functionality allover it simply fits more peoples way of working. Plus, it won't ruin anyones current workflow as doubleclicking isn't used anywhere yet.

*Although a simple one click to minimize when windows are maximized would work for me, I think it would break other peoples workflow.
