"Slot Autogrant" List

Post by DeeJay » 2003-05-02 13:11

Keeping this thread alive, as it's exactly what several users and I have been discussing! =)

The implementation Arne, GargoyleMT and others seem to be leaning toward is a list in a separate window, similar to the DL queue window, showing only users you wish to autogrant slots to. I think it would be a nice visual change, too, since all other windows like to stretch as far across the screen as you'll let them, regardless of how tall they are.

No mention seems to be made of a limit, however. I would ideally NOT want 50 ppl DLing from me due to favorites auto-granting. I would, however, like to be able to control the limit.

It would be nice to show info such as "last connected", slots, share size, etc, but I don't know what impact it would have on hub traffic.


Glad it's been considered for near release. Here's one more hope that we see it!

Post by GargoyleMT » 2003-05-02 13:39

Twink wrote:wouldn't autogranting to the ops be a bad idea?, cos then users can block their normal slot so no one can download, but when ops try to follow this up they can get a slot so aren't worried?


Auto-granting does not "lock" slots. Not the way I think of it, nor have implemented it.

DeeJay wrote:The implementation Arne, GargoyleMT and others seem to be leaning toward is a list in a separate window, similar to the DL queue window, showing only users you wish to autogrant slots to. I think it would be a nice visual change, too, since all other windows like to stretch as far across the screen as you'll let them, regardless of how tall they are.


Well, the Favorite Users window is currently... useless. It literally does nothing. I changed it to have checkboxes (to conrol granting) like the Favorite Hubs window, as well as adding some additional columns. I didn't give it the full treatment of extending it to be totally useful, just enough to fill my needs.

Although a limit to granted slots might be nice, it's really meant to be used sparingly. Right now, there's only two users on my list who are auto-granted slots, and one is a 56k user. Sparingly, as a last resort or perk. If "# of granted slots" is controllable, it will effectively recreate the slot system for "elite" users. Plus hub ops whose rules depend on "maximum slots' will want it advertised.
