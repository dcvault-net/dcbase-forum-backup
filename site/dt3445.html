Icons, Toolbars & Windows

Post by NanoFusion » 2003-06-10 06:06

These are one the minor things but it would really helpful if they can be addressed at some point:

I like that you can have the Menu bar and the Toolbar(icons) in the same pane (and it makes sense to do so since there is a lot more horizontal screen space available) but this change in Toolbar's position is lost once DC++ has been exited. So, it reverts back to its original position at startup.

Also, there is enough space here to have icons for every command under the File menu (I know most of you probably use the Hotkeys). Icons size could be customizable, Small and Large? The current size is large enough.

Moreover, when Windows are minimized, e.g Search, it should go down under the Tab at the bottom(above Status Bar) rather than set Window Size 0,0. The Title bar of these minimized windows should not be required if you have Tabs (that are more efficient). Clicking on the Tab toggles Minimize/Maximize stage, Right click Closes, so Title Bars of minimized windows are pretty useless.
