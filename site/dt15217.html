Re: File list automatic downloads

Post by GargoyleMT » 2005-11-04 02:13

Badpojk wrote:Is there any setting where this can be deactivated?

Yes: "Automatically Match Queue for Auto Search Hits"

Badpojk wrote:Is there any benefit of having downloaded file lists when searching for alternatives?

Of course, or it wouldn't have been implemented. Without matching, you have to do a search for each file in your queue that the user is a source for. With matching, you do one search, and DC++ downloads their list and adds them as alternate sources for all applicable files. It saves hub bandwidth, which lets the hub support more users.
