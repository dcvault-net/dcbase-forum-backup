How to get differnt shares for differnt hubs(works on WinXP)

Post by FredRoski » 2003-08-26 01:53

I run a hub, some filess are not allowed, so I share them in another hub. Say one is SHN's, the other is MP3's.
I start off connecting to DC++, or oDC, I set up my username, say user1. I connect to my SHN hub with my SHN files shared.
Next, I create another user accnt on my computer.
I hit start, click on control panel. Go to user accnt, click on create new user accnt, type in a name you want for the accnt. Make sure you select computer administrator (just to make sure it works). Click on create accnt, it brings you to the user accnt menu. Click on add password. type in the password twice, and add a clue in case you forget.
Now right click DC++ or oDC, select the following user, pick you new accnt name, and type in your password. Hit ok. Go in and change your username (user2)and remove all shn shares and add mp3 shares to your shares. type in the address of the mp3 hub, and your all set. The only drawback is, I think everytime you start your comptuter, and do this process, you have to remove your shares, and add your other shares. Other then that, it is easy to have 2 DC++ running, then 1 DC++ and NMDC, DC is really archiac. Sorry for the step by step, but its the easiest way to let newbies and others to know how to accomplish this. Now for all the insults! I think I read something about this on another post. I have XP, so I dont know if works on any other platforms?
