Well, you still could use an alternative hublist ( http://dcpp.net/wiki/index.php/Public_Hublists ).

If you receive an error on downloading a hublist, it is either temporary not available or even no longer active. Better remove that hublist in question and use another (active) one in your client (View Public hubs [ctrl+p] -> Configure).

Adding various active hublists (taken from alternative hublists wiki entry) in a swift (copypaste) to your DC++ client (based on 0.698)

Note that the line in Step 6 might become outdated.
Make sure to check Problem with the Public Hublist (List of Hubs) and the wiki entry for additional descriptions.

* Open the folder where the dc++ executable resides
* Open DCPlusPlus.xml in a text editor
* Find "<HublistServers>" (it's between "</FavoritesFrameWidths>" and before <QueueFrameOrder>)
* Select the whole line
* Delete the selected line (Press either the backspace or the Delete button on your keyboard)
* Insert the following into its place:

Code: Select all

<HublistServers>http://hub2list.redirectme.net/PublicHubList.xml.bz2;http://hub2list.no-ip.com/PublicHubList.xml.bz2;http://hub2list.no-ip.org/PublicHubList.xml.bz2;http://hubs.ath.cx/hublist.xml.bz2;http://www.dchublist.biz/PublicHublist.xml.bz2;http://dchublist.com/hublist.xml.bz2;http://hublist.dc-hub.eu/hublist/hublist.xml.bz2;http://awenet.info/hublist/PublicHubList.xml.bz2;http://www.awenet.info/hublist/PublicHubList.xml.bz2;http://www.freeweb.hu/alagnetwork/hublist.xml.bz2;http://idiota.sytes.net/PublicHublist.xml.bz2;http://www.hublist.co.uk/hublist.xml.bz2;http://inter.ancient.pl/inter/hublist.xml.bz2;http://sghdc.no-ip.org/download?file=AllHublist.xml.bz2;http://dreamland.gotdns.org/PublicHubList.config.bz2;http://www.freeweb.hu/pankeey/dc-hubz/pankeey-dchubz.config.bz2;http://dcinfo.sytes.net/publichublist.config.bz2;http://www.dc-resources.com/downloads/hublist.config.bz2;http://www.dchublist.biz/PublicHublist.config.bz2;http://www.dcinfo.org/publichublist.config.bz2;http://dcreg.mine.nu/PublicHubList.config.bz2;http://hublist.wikfall.se/dc/publichublist.config;http://maxweb.no-ip.com/PublicHubList.config;http://www.dchublist.com/hublist.config.bz2;http://hublist.adrenaline-network.com/PublicHubList.config;http://dchublist.com/hublist.config.bz2;http://www.hubs-list.com/PublicHubList.config.bz2;http://www.freenfo.net/PublicHubList.config.bz2;http://www.galy.szm.sk/CZHubListON.config;http://www.dcnet.be/publichublist.config.bz2;http://dcinfo.sytes.net/hungaryhublist.config.bz2;http://nevienc.sytes.net/dchl.config;http://www.xboss.ro/PublicHubList.config;http://bridefan.no-ip.info:88/rooms.bz2;http://www.zpoc.com/rooms.config;http://rexik.wz.cz/hublist.txt;http://hubilista.net/PublicHubList.config.bz2;http://www.dchublist.biz/HungarianHublist.xml.bz2;http://www.dchublist.biz/HungarianHublist.config.bz2;http://navi.deltaanime.net/~apnfsta/apnf/hublist/PublicHublist.config.bz2;http://sghdc.no-ip.org/download?file=PublicHubList.xml;http://navi.deltaanime.net/~apnfsta/apnf/hublist/adchublist.xml.bz2</HublistServers>
* (Ignore this step if you don't run DC++) Close the DC++ client
* Save the DCPlusPlus.xml file (make sure its been saved with the original filename and not been appended with .txt)
* (Re-)start your DC++ client
