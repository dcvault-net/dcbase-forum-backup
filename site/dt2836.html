Re: Status window for system msg and bots

Post by Wisp » 2004-03-29 10:43

I already suggested this feature, this is what i wanted to see in a status window
  • "hub messages" (like: "disconnected/reconnected from hub foo", futhermore things like kicks, bans, hub messages, etc)
  • filelist messages (like "filelist reloaded", "finished/failed hashing: file.txt")
  • chat log (all the conversations you had)
  • search log (like: "searched for file.avi, 0 results", "matched 10 items for user abc12")
  • transfer log (like: "disconnected by user123", "switching to source:user2","started downloading from user3","warning: disk full")
  • custom (let the user decide what events are showed here)
  • all (show all the events)
(and there are more things you can think of)

Also, there could be tiny icons for each sort of action, to have a nice clean overview, and maybe a text file to output everything (so you can read back things from previous dc++ sessions)

The current way is to log all the events to the statusbar, but this is barely readable and most times things happen in the background so you are unable to notice it.
