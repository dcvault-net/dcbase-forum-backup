select multiple files for "Search for Alternatives"

Post by Duke|MyU » 2003-08-30 13:06

When downloading folders consisting of multiple RAR files (or multiple zip files, or whatever.....) , if I right click on each individual file, I can select "Search for Alternative".... However, if I highlight several files at the same time, that selection option disappears.

The hub I use has several users sharing the same files, in order to enable downloaders to spread out the bandwidth.

The problem is that I have to manually highlight each and every file, one at a time, and do the Search for Alternatives for every one of them in order to get all possible files in the folder queued up from the multiple sources.

Could you consider adding the ability to highlight a block of files from the same download folder, and do a Search for Alternnatives for all, at one time? It would save me lots of key clicks, dealing with hundreds of files at a time.

Thanks for considering this one. I know others have suggested similar features, but have asked about it from odd angles. I think this suggestion is much more straight forward.
