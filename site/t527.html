Thus the return of Toast

Post by Toast » Sat Jul 04, 2009 11:13 am

Hi everyone, im back

Ive been moving got some small stuff still to fix and a "semi stable" Internet connection but thats another thing for the ISP technician to look at. I now got a small apartment in the town i grew up in until during the economic recession the funny thing about that is that the broadband is actually faster here then in the city, im gonna submit some pictures over how it looks when its done.

So ive seen that alot of stuff has been going on in the development community like the following stuff:
  • DC++ with limiter
  • StrongDC++ with DHT
  • Some new ideas for specs
  • uhub with ADCS (still missing spec in wiki ^^)
  • DCWatch with Swedish translations
So lets look at that list then

DC++
So i know that this new feature is gonna be hated by the nmdc people but looking from a logical point of view it makes sense to implement a limiter if we look at other p2p programs all of them contain a limiter to set speeds to control traffic, as i understood it cologic was the initiator behind the idea and the idea was approved by Arne (correct me if im wrong.)

The client is available on launchpad all of this is testing so far and its not certain that its gonna be included into the client but its still interesting the limiter has some issues so thats why its not a certain inclusion yet.

1788. By cologic on 2009-06-28 bandwidth throttling
http://bazaar.launchpad.net/~dcplusplus ... ision/1788

StrongDC++
This feature has been reported on before here on ADCPortal, im glad to report that BigMuscle is in test phase this idea might just prove to be a life saver for the network in general since using for search DHT engine can prove to be really powerful

http://strongdc.sourceforge.net/download/dht_test.7z
http://strongdc.sourceforge.net/forum/v ... f=0&t=5811

New spec ideas
Im glad to report that our junior developer darkKlor is thinking of ways to improve the protocol with thoughts on a new spec for creating chat channels (aka opchat etc.), This was a hot topic on DCDev Public awhile ago so im glad to see talk about it here on ADCPortal.

uHub
So alot of stuff is happening on uHub as i understand it glad to see that this project is moving since this is a great hubsoft (still just missing a good antispam system) but thats beside the point in this article as ive understand it uHub has gotten ADCS support which is great but a spec proposal for the adcs is still no where to be found

http://github.com/janvidar/uhub/tree/master

DCWatch
So on my time offline i got some files from CyB for DCWatch to translate so i can now say that the next version will have a swedish translation, i can also announce that DCWatch has now got a working phishtank url checker
all i got to say is that DCWatch is going to be a great all around bot and i hope people help out in this project.

http://www.dcwatch.hu/files/translation_template.zip
http://dcwatch.hu/en/node/92
http://dcwatch.hu/en/node/108

So rounding up it seems i gotta play alot of catch up with Developers getting the full info on projects and i do hope they help out and DAMN ITS NICE TO BE BACK

Toast - ADCPortal Creator/Maintainer
