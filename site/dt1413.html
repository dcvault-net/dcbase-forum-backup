Post by rtfmoz » 2003-03-12 08:52

I had this same problem and fixed it today using another method. I dont know if this is related.

I was planning to modify dc++ but had trouble making it compile. Was mucking around with include paths and ended up with a compile that would abort immediately after connecting to a hub. My client connects to my favourites immediately on startup. I dont use a public hub list generally unless I am looking for new hubs.

With the following compile settings it stopped aborting on startup.

Global Include Settings (Tools->Options): wtlport
DCPlusPlus Include Settings: stlport
Client Include Settings: stlport

NB: In my installation, wtlport and stlport are subdirectories in the main source code directory.

Go figure? Worked for me.
