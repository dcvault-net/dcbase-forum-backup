Sed gave it to me after I bugged him

Code: Select all

-- vim:ts=4:sw=4:noet

function dchpp.clientMessage( client, msg )
        local cmd = string.sub( msg, 1, 4 )
        if cmd == "+me " then
           dchpp.sendToAll( "* "..client:getNick().." "..string.sub( msg, 5 ).."|" )
           return dchpp.ACTION_STOP
        end
end

I can't seem to run it in daemon mode in linux. It just dies automatically. command-line mode seems to work fine though.

here's some changes in the readme I'd suggest:

Code: Select all

-- Installation --

1. Unextract all files into a directory of your choice. By default the config files will be looked for in /etc/dchpp. You can specify a directory of your choice by adding the -c command
2. Open dchpp.xml with notepad and check that all settings are to your satisfaction. If you don't understand
   a setting you're most probably better off leaving it alone.
3. Open the other xml's you'll find in the config dir. Most important are levels.xml and users.xml.

4. Try starting the hub by opening a command prompt and typing "dchpp". When the hub has started, you should
   be able to connect to it with a client of your choice. If something doesn't work, make sure you've enabled
   logging, and check the log file for hints why things didn't work out.
5. Edit motd.txt to your liking.
6. * Linux only *
   To run the hub start it with "dchpp <network card>"
      *note: you may have to be root to run dchpp*
6. * Windows only *
   To run the hub as a service, install it with "dchpp -i <name>". A service with the name <name> will be installed,
   and you can then use "net start <name>" to start it. If you want to run multiple hubs as services, use 
   "dchpp -i <name>" with a different name for each service (put them in different directories to use different
   config files). To uninstall, type "dchpp -u <name>".
