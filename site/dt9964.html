Share Source Profile For Each Hub

Post by Timzone8 » 2004-05-02 08:50

I'd like to see DC++ with the ability to give the user the option to create Share Source Profiles that contain links like the current share option, but with multiple profiles so that one can be allocated to a certain Genre Hub.
For Example:
C:\Anime - "Anime" --> Anime-Hub [Share:Anime]
C:\Music - "Music" --> Music-Hub [Share:Music]
C:\Movies - "Movies" --> Movies-Hub [Share:Movies]
et cetera.
Profiles should be able to created via a standard text box and "create" button. Then the profile should be selectable via a drop-down menu where the first area below it has the standard share-function and the area below that should show Favourite hubs in the allocated profile, and so that the favourites has a button "Add Share Profile".
It's just a suggestion, I think a fair few people would agree that it's a good feature.
/edit - A "Default" share profile would be needed to automatically assign itself to a hub just opened that isn't in favourites.. //
