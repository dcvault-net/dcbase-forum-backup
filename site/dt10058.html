Post by Wisp » 2004-05-19 10:15

GargoyleMT wrote:Not a feature that's likely to go anywhere.

I think this particular feature is a little bit hard to implement, but something similar could work, like a simple hub-script which enables users to vote for someone who they think is faking or is misbehaving. When there are more than x% voters, the specific user could get kicked

You have the same principle on gameservers, a user can start a vote when there is a cheater, and when >50% of the people agree the user is kicked.

The feature could also be implemented without the option to kick someone, but only to vote for a certain user, the OP can occasionally check the incoming votes, and when a certain user has a lot of votes for fakesharing, the OP can kick him

This feature would be not only usefull for fakesharers, but also people who have a low upload like 16kb, and then open 20 slots and connect to >10 hubs at the same time, when someone wants to download a file, the speed will vary between 500b/s to 1kb/s.. so in a lot of cases the slot is completely useless. Users like that could be kicked when a feature like this exist.
