Post by TheParanoidOne » 2003-09-12 14:46

DC++ has 3 mini-slots that it will use for files under a certain size (16KB IIRC). If the file list is larger than this, then it uses a standard slot.

There is always the possibility that the users are faking and/or slotblocking. But there is also the possibility that they may just be out of slots at the moment. The best thing to do would be to ask them for a slot so you can get their list. I've seen a number of hubs where one of the rules is "If an OP asks you for a slot, give him one". You could implement something like that.

TheParanoidOne wrote:DC++ has 3 mini-slots that it will use for files under a certain size (16KB IIRC). If the file list is larger than this, then it uses a standard slot.

filelists and small files (16kB yes) are considered small files, and will use a minislot (unless the user has free slots).
and... OPs are always granted a minislot

so if you can't get a list or small file from a user when you're an OP, the user is not using (an unmodified) DC++
