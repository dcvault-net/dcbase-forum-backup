Post by Lundis » 2004-07-12 10:01

Okey, I have another stupid suggestion you can ignore and dislike.

With 0.403 you can move the tabs around which is nice.
I suggest to have the option to fix the tab order so it goes to the right (and back to the left again), even if new windows pop up.
This way you will always know where the focus will go, cause with 0.305 and earlier when a new window popped up the order became different. And with later versions I think it's very hard to know even if no new windows opened up.

And it's also possible to work in two windows that are far from each other, just move them next to each other and tab between them.
