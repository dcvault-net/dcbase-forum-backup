Sometimes when i download a film there is an error at some point resulting in bad frames in the film (such as it goes green for a sec or something) I normally redownload the film so i can get the frames i need to replace and reedit them into the film with Virtual Dub. I was thinking what if in DC++ i could right click a file in the search window and have a "Download Part" option in the context menu. A dialog box will pop up and ask me what range of bytes i wanted it would start downloading and when it finishs it will make a file called say "Film[part563938-565753].avi". It would save me and people i know alot of time redownloading films. Could you implament this feature?

This is why bitzi.com exists

Post by GargoyleMT » 2003-10-06 16:37

Once hashes work, and we get a SHA1 of the file, "we" can integrate with bitzi.com. Shareaza, an application that already offers this integration (but is a client on the Gnutella2 and eDonkey networks), allows users to right click on a search result and to to a webpage where the file is rated.

Combined with something like divfix integration, so you can flag bad AVI files before they're shared, this can really help the problem of corrupt copies of files floating around.

(All in theory.)
