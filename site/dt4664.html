Post by TheParanoidOne » 2003-08-10 16:15

There are certainly tools for remote control, such as VNC which allows you to graphically control another machine. But you will come up against a limitation of Windows - the fact that it is not a truly multiuser system. It is a single user system with some mutli user capabilities bolted on.

You cannot therefore have two people running a GUI on the same machine at the same time. If you were using some form of Unix variant though, this wouldn't be an issue.

If you go down the VNC route, you would have to make arrangements about who would use the machine at what time.

Would it not be easier in the long run for your brother to just give you a list of things that he would like?
